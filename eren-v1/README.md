# 艾伦像素动作素材

- 来源目录：`D:/H5自动战斗原型/reference/艾伦`
- 游戏帧：96×112 px、RGBA 透明背景；统一底边基准。
- 已接入：待机、降落、跑步、普通攻击起手/出拳/收手、受击、闪避、倒地，以及两套主动技能动作。
- 普通攻击播放顺序：`attack_windup.png`（挥拳起手）→ `punch.png`（挥拳）→ `attack_recover.png`（收手）；播放时长 90/140/90 ms，倍速统一缩短。
- 入场顺序：`fall_2.png`（降落2，下落帧，2000 ms）→ `fall_1.png`（降落1，落地帧，680 ms）→ `fall_2.png`（起身反弹帧，300 ms）；本轮将开头的 `fall_2` 下落帧额外延长 1000 ms，总降落时间 2980 ms，之后才进入 Pose。
- 跑步帧从 `run_1.svg`、`run_2.svg` 中提取其内嵌 PNG，再作为两帧循环播放。
- 新提供的挥拳、受击和闪避 PNG 带棋盘格底色；接入前按边缘连通的中性色区域去底，白色角色细节保留。帧以最近邻方式缩放，维持像素边缘。
- `death.png` 从 `death.svg` 内嵌的横向倒地画面中提取。
- 技能 1 使用 `技能1_1.png`–`技能1_3.png`；技能 2 当前仅使用 `技能2_1.png` 与 `技能2-2.png`，后两张旧素材不参与播放。每张源图都映射为单独动作帧，不显示整张素材表。
- 技能播放顺序和帧时长见 `animation.json`。两套动作都先原地播放第 1 帧，再循环跑步帧冲刺到目标附近，最后播放剩余技能帧；攻击结算仍只使用预先生成的一条战斗事件。
- 技能动作姿势本身包含前倾/横向出招构图；此前通用 `punch-snap` 会额外压扁 Y 轴。现在该挤压动画仅用于普通挥拳，技能动作帧保持等比显示。
- 具体来源、帧映射和动作顺序见 `animation.json`。
