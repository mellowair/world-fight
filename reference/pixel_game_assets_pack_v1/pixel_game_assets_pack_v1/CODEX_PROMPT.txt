请先阅读本目录的 `README_素材说明.md`，再对现有游戏做增量修改。

本轮素材包中的 `backgrounds/route_city_grass_background.png` 是可以直接作为路线选择背景使用的本地 PNG；`references/` 中的图片仅用于视觉参考，不是可直接播放的 Sprite Sheet，也不要把它们整张放进游戏。

任务：
1. 将路线选择页面背景替换为新背景，保留现有游戏角色、四类木质路牌和路线逻辑。适配手机竖屏，使用合适的 cover 裁切，不拉伸图片。
2. 角色待机时增加轻微循环动作；如果当前角色只有静态素材，不要声称已实现真正逐帧待机，可以先做小幅呼吸起伏并在状态文档中注明。
3. 近战角色跑动时在脚底后方生成短暂像素尘土粒子，粒子自动清理。
4. 命中时播放简洁像素冲击效果；挥击弧光应跟随攻击时序，不能出现不透明矩形。
5. 受击时随机选择后仰或眩晕交叉眼睛中的一种，不要同时播放；闪避不触发受击；死亡时只显示角色倒地，不显示星星。
6. 适当缩短双方战斗站位距离，保留前排靠近中央、后排位于己方前排后方的规则。
7. 如果参考图中的特效无法无损裁切成透明素材，请用独立 SVG/CSS 像素图形重新制作单个特效，不要直接使用带背景的参考图。
8. 不改变战斗计算和路线状态机。动画不能重复扣血、重判暴击/闪避或改变胜负。
9. 运行测试，检查手机竖屏，更新 PROJECT_STATUS.md，记录真实使用的素材路径、测试结果和未完成项。
