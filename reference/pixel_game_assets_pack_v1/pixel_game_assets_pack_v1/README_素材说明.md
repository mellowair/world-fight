# 像素肉鸽游戏素材包 V1

## 文件清单

### backgrounds/route_city_grass_background.png
路线选择场景背景：夜色霓虹城市、暗红天空、前景草地与泥土地面。建议作为背景层使用，角色和路牌继续由游戏独立渲染。

### references/combat_effects_reference_sheet.png
战斗特效参考：冲击爆发、尘土、挥击弧光、速度线、星星和暴击效果。此图用于视觉参考，生成图中存在背景光晕，不应直接作为透明特效 Sprite Sheet 整张播放。

### references/full_game_art_direction_reference.png
综合美术方向参考：角色动作、路牌、背景、特效与战斗构图。它是参考图，不是可直接切片的正式素材。

### references/organized_asset_reference_sheet.png
另一张综合资产布局参考，用于说明动作类型和场景组成，同样不应直接放进游戏。

## 接入建议
- 先接入路线背景。
- 路牌沿用游戏原有木牌和图标，不要从综合参考图中直接裁切带文字的路牌。
- 对特效参考图，优先由开发者按视觉风格制作独立透明 SVG/Canvas 特效；如果要裁切 PNG，需检查每个效果周围的背景光晕和矩形边缘。
- 角色动画继续使用项目内现有角色素材，不要用综合参考图里的鸣人小图直接替换角色。
- 角色受击时随机播放后仰或眩晕两种表现之一；死亡时只倒地，不显示星星。
- 所有动画只回放已经结算的战斗事件，不改变伤害、HP、闪避、暴击或胜负。
