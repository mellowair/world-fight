# 普通敌人外观素材

| 文件 | 来源 | 战斗用途 |
| --- | --- | --- |
| `giant.png` | `reference/普通敌人素材/普通巨人.png`，128×144 RGBA 原图 | 前排近战外观之一 |
| `slime.png` | `reference/普通敌人素材/史莱姆.png`，1199×1312，经 imagegen 去除不透明棋盘底色 | 前排近战外观之一 |
| `mage.png` | `reference/普通敌人素材/小法师.png`，128×144 RGBA 原图 | 后排法师外观 |

本轮替换使用 reference 中的新图。巨人和小法师原图已透明，直接复制且不修改像素或尺寸；史莱姆原图的棋盘格实际不透明，因此使用 imagegen 移除背景并保持原画幅。三张游戏文件均为独立透明 RGBA PNG。`visualConfig.js` 分别配置显示帧和缩放（巨人 1.05、史莱姆 0.87、小法师 0.86）；原始像素尺寸无需统一，脚底中心由共同的 `.sprite-visual` 容器锚定。

前排外观在进入普通战斗节点时，由地图种子和节点 ID 独立决定为巨人或史莱姆，同一遭遇固定不变。`guard`、`mage` 战斗模板 ID、属性、站位与伤害逻辑保留；Boss 迪达拉仍在 Boss 战斗副本中使用专属素材。当前三个普通敌人外观均为静态帧，攻击、受击和倒地继续复用现有通用表现。
