# 艾伦像素动作素材

- 来源目录：`D:/H5自动战斗原型/reference/艾伦`
- 游戏帧：96×112 px、RGBA 透明背景；统一底边基准。
- 已接入：待机、降落、跑步、普通攻击起手/出拳/收手、受击、闪避、倒地。
- 普通攻击播放顺序：`attack_windup.png`（挥拳起手）→ `punch.png`（挥拳）→ `attack_recover.png`（收手）；播放时长 90/140/90 ms，倍速统一缩短。
- 入场顺序：`fall_2.png`（降落2，下落帧，720 ms）→ `fall_1.png`（降落1，落地帧，330 ms）。
- 跑步帧从 `run_1.svg`、`run_2.svg` 中提取其内嵌 PNG，再作为两帧循环播放。
- 新提供的挥拳、受击和闪避 PNG 带棋盘格底色；接入前按边缘连通的中性色区域去底，白色角色细节保留。帧以最近邻方式缩放，维持像素边缘。
- `death.png` 从 `death.svg` 内嵌的横向倒地画面中提取。
- 具体来源、帧映射和动作顺序见 `animation.json`。
- 艾伦技能动画素材未提供；技能视觉仍复用普通战斗表现。
